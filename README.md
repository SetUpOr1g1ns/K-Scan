# K-Scan

**K-Scan** aims to be a *Kairos* of web vulnerability analysis. This tool allows you to check your website for common cibersecurity issues at the exact moment (Kairos): **just before launch**.

---

## 🖥️ Usage (Text-Based Interface)

K-Scan features an interactive Text-Based User Interface (TUI) directly inside your terminal (both Windows and Linux). 
Just Use: 
```bash
kscan
```
or 
```bash
python kscan
```

### Navigating the Interface
* **Arrow Keys / Tab:** Move between scan options and input fields.
* **Enter:** Confirm what has been selected.
* **Esc / Q:** Quit the application.
